# Sales Data Analysis Using SQL

## 📌 Project Overview
This project analyzes sales data to uncover trends in customer behavior and product performance.

## 🛠 Tools Used
- MySQL Workbench
- SQL

## 📊 Analysis
- Total revenue
- Product category performance
- Customer spending behavior
- Payment method usage

## 🔥 Key Insights
- Electronics generated the highest revenue
- Card was the most used payment method
- Female customers spent more overall
